How to read this (and what to do when it’s “GO”)

1) “BoM Aurora Notices” card
  • Alert is strongest (conditions happening / imminent), then Watch, then Outlook.
  • If there’s no notice, NSW is usually a no-go unless the K-index spikes unusually high.
2) K-index chart (last 72h)
  • Higher = stronger geomagnetic activity.
  • Tasmania can work at lower values than NSW.
  • NSW usually needs a rare event plus clear skies and a dark southern horizon.
3) Cloud chart (next 48h) + “Cloud cover next 6 hours”
  • Lower cloud % is better. Treat <30–40% as “worth trying”.
  • Even with great space weather, cloud / haze / sea mist can wipe it out.
4) If it says GO / MAYBE — do this
  • Tap Build tonight’s plan → follow the checklist + directions.
  • Go during 9pm–2am (often best nearer midnight).
  • Moon: darker is better. Check your weather app for moonrise/moonset + illumination.
  • Safety: public access areas only; obey signs and any gate rules.
Data sources: BoM space weather (aurora notices + K-index) and Open-Meteo (cloud cover for selected spot).
